# Security Policy

## Supported Versions

AI Product Lab is an experimental engineering project under active development.

Only the latest version on the `main` branch is maintained. No production security guarantees or long-term support commitments are currently provided.

## Reporting a Vulnerability

Please report potential security vulnerabilities privately rather than opening a public GitHub issue.

Use GitHub's **Private Vulnerability Reporting** feature if it is enabled for this repository.

If private vulnerability reporting is unavailable, contact the repository maintainer through an established private channel. Do not publish exploit
